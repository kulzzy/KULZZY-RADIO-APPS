iPHONE & iPAD

Install Kulzzy Radio on your Apple device using Safari. No App Store download is required.

OPEN KULZZY RADIO

How to install on iPhone or iPad

  1. Open this page in Safari.
  2. Visit the Kulzzy Radio app using the button above.
  3. Tap the Share button in Safari.
  4. Select Add to Home Screen.
  5. Tap Add to finish installing.

This is a free web app installation, not an App Store download.

COMPUTERS & LAPTOPS

Install Kulzzy Radio on your Windows, Mac or Linux computer and access it directly from your desktop.

OPEN KULZZY RADIO

Windows — Google Chrome or Microsoft Edge

  1. Open Kulzzy Radio in Chrome or Edge.
  2. Look for the Install icon in the browser address bar.
  3. Click Install and follow the instructions.
  4. If the icon is not visible, open the browser menu and look for Install page as app.

Mac — Safari or Google Chrome

  1. Open Kulzzy Radio in Safari or Chrome.
  2. In Safari, use File → Add to Dock (on supported macOS versions).
  3. In Chrome, open the browser menu and select Install page as app if available.
  4. Follow the instructions to finish.

Linux — Google Chrome or Chromium

  1. Open Kulzzy Radio in Chrome or Chromium.
  2. Open the browser menu.
  3. Select Install page as app if available.
  4. Follow the instructions to finish.

Installation options may vary depending on your browser and operating system.
